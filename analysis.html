1. 数列の基礎

定義 1.1 — 数列

自然数全体 $\mathbb{N}$ を定義域とする写像 $a:\mathbb{N}\to\mathbb{R}$（あるいは $\mathbb{C}$）を 実数列（複素数列）という。通常 $a(n)$ を $a_n$ と書き、数列全体を $\{a_n\}_{n=1}^{\infty}$ と表す。

単調数列

名称条件
単調増加$a_n \le a_{n+1} \quad \forall n$
（狭義）単調増加$a_n < a_{n+1} \quad \forall n$
単調減少$a_n \ge a_{n+1} \quad \forall n$
（狭義）単調減少$a_n > a_{n+1} \quad \forall n$
定理 1.2 — 単調収束定理

単調増加かつ上に有界な数列、または単調減少かつ下に有界な数列は収束する。

2. 収束の定義（ε-N 論法）

定義 2.1 — 数列の収束

数列 $\{a_n\}$ が $\alpha \in \mathbb{R}$ に収束するとは、

$$\forall \varepsilon > 0,\; \exists N \in \mathbb{N} \;\text{s.t.}\; n > N \Rightarrow |a_n - \alpha| < \varepsilon$$

が成立することをいう。このとき $\displaystyle\lim_{n\to\infty} a_n = \alpha$ と書く。

定理 2.2 — コーシー列の収束

実数列（あるいはバナッハ空間内の列）がコーシー列、すなわち

$$\forall \varepsilon > 0,\; \exists N \;\text{s.t.}\; m,n > N \Rightarrow |a_m - a_n| < \varepsilon$$

を満たすならば収束する（実数の完備性）。

収束に関する基本性質

  • 極限の一意性：$\lim a_n = \alpha$ かつ $\lim a_n = \beta$ ならば $\alpha = \beta$。
  • 収束列は有界：$\{a_n\}$ が収束すれば $\exists M > 0$ s.t. $|a_n| \le M$ $(\forall n)$。
  • 挟み撃ち定理：$b_n \le a_n \le c_n$ かつ $\lim b_n = \lim c_n = L$ ならば $\lim a_n = L$。

3. ガウス数列（算術幾何平均列）

ガウス数列（Gauss sequence）とは、C. F. Gauss が楕円積分の研究で導入した 算術幾何平均（Arithmetic-Geometric Mean; AGM）を定義する数列のことである。

定義 3.1 — ガウス数列（AGM 数列）

実数 $a_0 \ge b_0 > 0$ を与える。以下の漸化式で定まる二つの数列 $\{a_n\}$, $\{b_n\}$ をガウス数列という：

$$a_{n+1} = \frac{a_n + b_n}{2}, \qquad b_{n+1} = \sqrt{a_n b_n}$$

共通の収束先を $M(a_0, b_0)$ と書き、算術幾何平均という。

直感的なイメージ

算術平均 $A = \frac{a+b}{2}$ と幾何平均 $G = \sqrt{ab}$ を交互に適用すると、 二つの値が急速に互いに近づく。以下は $a_0=1,\, b_0 = 1/\sqrt{2}$ の場合の数値例：

4. ガウス数列の収束証明

以下では $a_0 \ge b_0 > 0$ を仮定する（$a_0 = b_0$ のとき自明に収束するので除く）。

補題 4.1 — AM-GM 不等式

正実数 $x, y > 0$ に対して

$$\frac{x+y}{2} \ge \sqrt{xy}$$

等号成立は $x = y$ のときに限る。

証明（補題 4.1）

$(\sqrt{x} - \sqrt{y})^2 \ge 0$ を展開すると $x - 2\sqrt{xy} + y \ge 0$。 整理して $\dfrac{x+y}{2} \ge \sqrt{xy}$。等号は $\sqrt{x}=\sqrt{y}$、 すなわち $x=y$ のとき。

□
補題 4.2 — $b_n \le b_{n+1} \le a_{n+1} \le a_n$（挟み込み）

すべての $n \ge 0$ に対して $b_n \le b_{n+1} \le a_{n+1} \le a_n$ が成立する。

証明（補題 4.2）

数学的帰納法で示す。$n=0$ のとき $a_0 \ge b_0 > 0$ は仮定より成立。 $a_n \ge b_n > 0$ を帰納的仮定とする。

  1. $b_{n+1} \le a_{n+1}$（帰納的仮定から従う）： 帰納的仮定 $a_n \ge b_n$ と補題 4.1 より $a_{n+1} = \dfrac{a_n+b_n}{2} \ge \sqrt{a_n b_n} = b_{n+1}$。
  2. $a_{n+1} \le a_n$（$\{a_n\}$ は単調減少）： $b_n \le a_n$（帰納的仮定）より $a_{n+1} = \dfrac{a_n + b_n}{2} \le \dfrac{a_n + a_n}{2} = a_n$。
  3. $b_n \le b_{n+1}$（$\{b_n\}$ は単調増加）： $a_n \ge b_n$（帰納的仮定）より $b_{n+1} = \sqrt{a_n b_n} \ge \sqrt{b_n \cdot b_n} = b_n$。

以上を合わせると $b_n \le b_{n+1} \le a_{n+1} \le a_n$ が示された。 帰納法により全 $n \ge 0$ で成立する。

□
定理 4.3 — ガウス数列の収束

$a_0 \ge b_0 > 0$ とする。ガウス数列 $\{a_n\},\{b_n\}$ はともに同一の正の値 $M = M(a_0, b_0)$ に収束する：

$$\lim_{n\to\infty} a_n = \lim_{n\to\infty} b_n = M(a_0, b_0)$$
証明（定理 4.3）
  1. 有界性の確認。 補題 4.2 より、任意の $n$ に対して $$b_0 \le b_1 \le \cdots \le b_n \le a_n \le \cdots \le a_1 \le a_0$$ が成立する。したがって $\{a_n\}$ は $b_0 > 0$ を下界に持ち、 $\{b_n\}$ は $a_0$ を上界に持つ。
  2. 単調収束定理の適用。 $\{a_n\}$ は単調減少かつ下に有界（$\ge b_0 > 0$）なので、 単調収束定理（定理 1.2）より収束する；その極限を $\alpha$ とする。 同様に $\{b_n\}$ は単調増加かつ上に有界（$\le a_0$）なので収束する； その極限を $\beta$ とする。
  3. 極限の一致の証明。 漸化式の両辺で $n \to \infty$ の極限を取ると $$\alpha = \lim_{n\to\infty} a_{n+1} = \lim_{n\to\infty} \frac{a_n + b_n}{2} = \frac{\alpha + \beta}{2}$$ よって $2\alpha = \alpha + \beta$、すなわち $\alpha = \beta =: M$。
  4. 正値性の確認。 $M = \lim b_n \ge b_0 > 0$。

以上より $\displaystyle\lim_{n\to\infty} a_n = \lim_{n\to\infty} b_n = M(a_0, b_0) > 0$。

□
系 4.4 — 2次収束（収束の速さ）

誤差 $\varepsilon_n := a_n - b_n$ は次の不等式を満たす：

$$0 \le \varepsilon_{n+1} \le \frac{\varepsilon_n^2}{8 b_0}$$

したがって誤差は超指数的に（2次のオーダーで）$0$ に収束する。

証明（系 4.4）

算術平均・幾何平均の差を計算する：

$$\varepsilon_{n+1} = a_{n+1} - b_{n+1} = \frac{a_n + b_n}{2} - \sqrt{a_n b_n} = \frac{(\sqrt{a_n} - \sqrt{b_n})^2}{2}$$

$\sqrt{a_n} - \sqrt{b_n} = \dfrac{a_n - b_n}{\sqrt{a_n} + \sqrt{b_n}} \le \dfrac{\varepsilon_n}{2\sqrt{b_0}}$ なので（$b_n \ge b_0$ を利用）

$$\varepsilon_{n+1} \le \frac{1}{2}\left(\frac{\varepsilon_n}{2\sqrt{b_0}}\right)^2 = \frac{\varepsilon_n^2}{8 b_0}$$
□
注意

2次収束は非常に速い収束率を意味する。例えば初期誤差 $\varepsilon_0 = 0.3$、 $b_0 = 0.7$ のとき、$\varepsilon_1 \lesssim 0.004$、$\varepsilon_2 \lesssim 10^{-5}$、 $\varepsilon_3 \lesssim 10^{-10}$、…と正確な桁数がほぼ 2 倍ずつ増加する。 これが AGM が計算機科学での高精度計算（$\pi$ の計算など）に広く使われる理由である。

5. AGM の応用

5.1 楕円積分との関係

ガウスが AGM を発見した動機は、第 1 種完全楕円積分 $K(k) = \displaystyle\int_0^{\pi/2} \frac{d\theta}{\sqrt{1 - k^2 \sin^2\theta}}$ の計算であった。

定理 5.1 — Gauss の公式

$0 < k < 1$ に対して $k' = \sqrt{1 - k^2}$ とおく。$a_0 = 1,\; b_0 = k'$ として AGM 数列を構成すると

$$K(k) = \frac{\pi}{2\, M(1, k')}$$

この公式を用いると、有限回の算術・幾何平均演算だけで $K(k)$ を 任意精度で計算できる。

5.2 円周率 $\pi$ の高速計算

Brent–Salamin アルゴリズム（1976）は AGM に基づく $\pi$ の計算法であり、 各ステップで正確な桁数がほぼ 2 倍になる：

$a_0 = 1,\; b_0 = \dfrac{1}{\sqrt{2}},\; t_0 = \dfrac{1}{4},\; p_0 = 1$ として

$$a_{n+1} = \frac{a_n + b_n}{2}, \quad b_{n+1} = \sqrt{a_n b_n}, \quad t_{n+1} = t_n - p_n(a_n - a_{n+1})^2, \quad p_{n+1} = 2p_n$$ $$\pi \approx \frac{(a_n + b_n)^2}{4 t_n}$$

5.3 その他の関連公式

  • 第 2 種完全楕円積分 $E(k)$ もまた AGM を通じて計算可能。
  • 対数の超高速計算（Borwein の $\pi$ アルゴリズム群）。
  • 楕円曲線上のペアリング計算（暗号への応用）。

6. 連続と微分（解析の基礎）

定義 6.1 — 連続性

関数 $f: \mathbb{R} \to \mathbb{R}$ が点 $c$ で連続であるとは

$$\forall \varepsilon > 0,\; \exists \delta > 0 \;\text{s.t.}\; |x - c| < \delta \Rightarrow |f(x) - f(c)| < \varepsilon$$
定理 6.2 — 中間値定理

$f$ が閉区間 $[a, b]$ 上で連続で $f(a) \ne f(b)$ ならば、 $f(a)$ と $f(b)$ の間の任意の値 $y$ に対して $f(c) = y$ となる $c \in (a, b)$ が存在する。

定義 6.3 — 微分可能性

点 $c$ における微分係数（導関数の値）を

$$f'(c) = \lim_{h \to 0} \frac{f(c+h) - f(c)}{h}$$

と定義する。この極限が存在するとき $f$ は $c$ で微分可能という。

定理 6.4 — 平均値定理

$f$ が $[a,b]$ 上連続かつ $(a,b)$ 上微分可能ならば

$$\exists c \in (a, b) \;\text{s.t.}\; f'(c) = \frac{f(b) - f(a)}{b - a}$$

7. 積分

定義 7.1 — リーマン積分

区間 $[a, b]$ の分割 $\Delta: a = x_0 < x_1 < \cdots < x_n = b$ に対して リーマン和を $S(\Delta) = \displaystyle\sum_{i=1}^n f(\xi_i)(x_i - x_{i-1})$ と定義する。 分割の幅の最大値 $|\Delta| \to 0$ のとき $S(\Delta)$ が一定値 $I$ に収束するならば、 $f$ は $[a,b]$ 上リーマン積分可能といい $I = \displaystyle\int_a^b f(x)\,dx$ と書く。

定理 7.2 — 微積分の基本定理

$f$ が $[a, b]$ 上連続ならば、$F(x) = \displaystyle\int_a^x f(t)\,dt$ は $(a,b)$ 上微分可能で $F'(x) = f(x)$。さらに $G'=f$ となる任意の原始関数 $G$ に対して

$$\int_a^b f(x)\,dx = G(b) - G(a)$$

8. ガンマ関数と負の実数への拡張

8.1 正の実数上での定義

定義 8.1 — ガンマ関数（Euler の積分表示）

$\text{Re}(z) > 0$ に対して

$$\Gamma(z) = \int_0^{\infty} t^{z-1} e^{-t}\, dt$$

と定義する。この積分は $\text{Re}(z) > 0$ において絶対収束し、正則関数を定める。

8.2 関数等式と階乗との関係

定理 8.2 — 関数等式

$\text{Re}(z) > 0$ において

$$\Gamma(z+1) = z\,\Gamma(z)$$

とくに正整数 $n$ に対して $\Gamma(n) = (n-1)!$。

証明（定理 8.2）

部分積分により

$$\Gamma(z+1) = \int_0^\infty t^z e^{-t}\,dt = \Bigl[-t^z e^{-t}\Bigr]_0^\infty + z\int_0^\infty t^{z-1}e^{-t}\,dt = z\,\Gamma(z)$$

初期値 $\Gamma(1) = \displaystyle\int_0^\infty e^{-t}\,dt = 1$ と帰納法より $\Gamma(n)=(n-1)!$。

□

8.3 負の実数への拡張（解析接続）

ガンマ関数は $\text{Re}(z) > 0$ でのみ積分表示が収束するが、 関数等式 $\Gamma(z) = \dfrac{\Gamma(z+1)}{z}$ を用いて 解析接続により定義域を広げることができる。

定義 8.3 — 負の実数上のガンマ関数（漸化式による拡張）

$-n-1 < z < -n$（$n = 0, 1, 2, \ldots$）の実数に対して

$$\Gamma(z) = \frac{\Gamma(z+n+1)}{z(z+1)\cdots(z+n)}$$

と定義する。ここで右辺の $\Gamma(z+n+1)$ は $\text{Re}(z+n+1) > 0$ なので 積分表示で計算できる。

注意 — 極（ポール）の位置

分母 $z(z+1)\cdots(z+n)$ は $z = 0, -1, -2, \ldots, -n$ でゼロになるため、 $\Gamma(z)$ は非正整数 $z = 0, -1, -2, \ldots$ に1位の極を持ち、 それ以外の複素数全域で正則である。 極での留数は

$$\operatorname{Res}_{z=-n}\Gamma(z) = \frac{(-1)^n}{n!} \qquad (n = 0, 1, 2, \ldots)$$

8.4 負の値の計算例

関数等式を繰り返し適用して負の実数でのガンマ関数の値を求めることができる。 例えば $z = -\frac{1}{2}$ の場合：

$$\Gamma\!\left(-\tfrac{1}{2}\right) = \frac{\Gamma\!\left(\tfrac{1}{2}\right)}{-\tfrac{1}{2}} = \frac{\sqrt{\pi}}{-1/2} = -2\sqrt{\pi}$$

ここで $\Gamma\!\left(\dfrac{1}{2}\right) = \sqrt{\pi}$ を用いた。これは Gauss 積分 $\displaystyle\int_{-\infty}^{\infty} e^{-t^2}\,dt = \sqrt{\pi}$ の置換 $u = t^2$ から従う（Section 7 参照）。

8.5 Weierstrass 積表示

ガンマ関数の逆数は至るところ正則な関数であり、 Weierstrass の積展開で次のように表される：

$$\frac{1}{\Gamma(z)} = z\, e^{\gamma z} \prod_{n=1}^{\infty} \left(1 + \frac{z}{n}\right)e^{-z/n}$$

ここで $\gamma = \lim_{n\to\infty}\!\left(\sum_{k=1}^n \frac{1}{k} - \ln n\right) \approx 0.57722$ は Euler–Mascheroni 定数である。この表示は $z$ が非正整数のとき $1/\Gamma(z)=0$ となることを 直接示しており、それらの点がちょうど極になることと整合する。

定理 8.4 — 反射公式（Euler）

$z \notin \mathbb{Z}$ に対して

$$\Gamma(z)\,\Gamma(1-z) = \frac{\pi}{\sin(\pi z)}$$

この公式は $z = 1/2$ を代入すると $\Gamma(1/2)^2 = \pi$、 すなわち $\Gamma(1/2) = \sqrt{\pi}$ を与える。 また負の半整数での値（$z = -1/2, -3/2, \ldots$）を陽に計算するのに便利である。
